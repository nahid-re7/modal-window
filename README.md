modal window
.A simple and interactive modal window project built with HTML,CSS,Java Script.

About The Project 
.this project was developed as part of Jonas Schemdtmann's course.

it demonstrates how to creat and control modal windows using JavaScript DOM manipulation and event handling.


Features
.open modal windows by clicking buttons.
.close the modal by clicking the close button.
.close the modal by clicking the overlay.
.close the modal using the Escape key.
.Interactive user interface.



Technologies Used 
.HTML
.CSS
.JavaScript
